# Fast-Food Manufacturing Control

Multi-location manufacturing operations starter covering 5S, tool/fixture optimization, SMED changeovers, standardized production, inventory, quality and food-safety checks, workforce balancing, and continuous improvement.

This repository integration is a development starter, not a production-ready control system. Authentication/MFA, API authorization, KMS-backed encryption, immutable audit export, and production hardening remain implementation gates. Food-safety limits must be approved per site and product by qualified personnel; failed checks require a hold and must never be automatically released.

The remaining source files from the project archive are to be imported into this directory. No production deployment, POS/payment writes, or equipment-control actions are enabled.
